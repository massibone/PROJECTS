Iliade NLP Analysis (SQLite-based)
Analisi computazionale del testo dell'Iliade tramite pipeline NLP (spaCy) e modellazione di grafi su database relazionale (SQLite).
Perché SQLite: Inizialmente concepito per Neo4j, il progetto è stato ottimizzato per un database relazionale (SQLite) per garantire portabilità e facilità di analisi stilometrica senza necessità di server dedicati, mantenendo intatta la struttura a grafo tramite interrogazioni SQL avanzate.
